# Teaching Activity Hub

Interactive English activities for 1:1 virtual lessons, embedded into Canvas via iframe.

**Live site:** https://shoneyd.github.io/

## Structure
- `index.html` — the hub. Lists activities and generates Canvas embed codes.
- `activities/` — one self-contained HTML file per activity.
- `.nojekyll` — serves files as-is instead of running Jekyll.

## Adding an activity
1. Drop the `.html` file into `activities/`
2. Add an entry to the `ACTIVITIES` array near the bottom of `index.html`
3. Commit both. Live in 1–2 minutes.

## Note
This repository is public. Activities only — no student names, work, grades, or teaching notes.
