Part 2 — Read three blocks

Say each one out loud first, then write how it sounds using English letters. Take the block apart: what's the consonant, and what's the vowel?

고
너
스
Check my answers — after you've written all three

고 = go. ㄱ plus ㅗ. Flat vowel, so it sits underneath.

너 = neo, said like "nuh". ㄴ plus ㅓ. If you wrote no, you're close but you've slipped into ㅗ — ㅓ has relaxed, unrounded lips. It means "you", by the way.

스 = seu. ㅅ plus ㅡ. This is the vowel with no English version — "ee" with flat, spread lips. If you wrote su or soo, you've landed on ㅜ instead.

Got one wrong? Change it above — the box is still live, and what you fix is what gets submitted.
