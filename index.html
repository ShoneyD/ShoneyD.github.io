How to put one of these in Canvas

1. Click Copy embed code on the item you want.
2. In Canvas, open the assignment or page and click </> in the editor toolbar.
3. Paste. Switch back to the rich view — it appears inline.

The embed codes are generated from this page's own address, so they're always correct for your site.

Lesson pages built after August 2026 already carry their embed code inside the lesson file — copying a section from the lesson gives you the section and its working iframe in one go, so you don't need this page for those.

This site is public

GitHub Pages sites are reachable by anyone with the URL. That's fine for teaching material — but never put student names, student work, grades, or your teaching notes in this repository.

That's why lesson pages here are named by course and lesson and never by student. The named copy, with your run sheet and notes, stays in your local students/ folder.

Adding something new

Drop the .html file into lessons/, activities/ or resources/ — class subfolders inside those are fine and preferred for new material. Then add an entry to the ITEMS list at the bottom of index.html. Commit both.

To add a class, just type a new course value on an item. The tabs build themselves.

Or attach the file to Claude and say "add this to my hub" — you'll get the file plus an updated index.html, ready to upload together.
