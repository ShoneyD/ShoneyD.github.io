🦘 Verb Jump

Climb as high as you can. Some verbs need something to carry across. Some don’t. The verbs decide how high you fly.

How to play

  1. You bounce by yourself. You only steer: move the mouse (or your finger) left and right, or use ← →.
  2. Fly through a phrase bubble to carry it. You can carry one at a time. ↓ drops it.
  3. Every platform is a verb. Land on it and Lena makes a sentence: Lena + verb + whatever you’re carrying.
  4. If the sentence works, you bounce. If it really works, you fly. If it doesn’t work, read the message to find out why.
  5. Falling is fine. A cloud catches you.
  6. Reach the 🚩 summit, then press the green button for the next climb. P pauses. ⛶ makes it full screen.

Climb 1 — Base Camp

The What? test

Say the verb, then ask “… what?”

Needs an object (transitive)Doesn’t take one (intransitive)
Lena grabbed… what? → the ball. Without it, the sentence is broken. Lena laughed. Laughed what? Nothing. It’s already finished.
Land with a bubble → 🚀 you fly.
Land empty → it crumbles.		 Land empty → you bounce.
Land with a bubble → you lose the bubble.

The platforms don’t tell you which kind they are. You have to decide before you land.

Done looks like: you reach the 🚩 summit. Try to fly 🚀 at least five times on the way.

Climb 2 — Double Agents & Fake Objects

Two new things NEW

1. Double agents. Some verbs work both ways: Lena won the medal. / Lena won! Land with an object and you fly. Land without one and you still bounce.

2. Fake objects. Some bubbles look like objects, but they answer where, when or how, not what.

Real object (answers what?)Fake object (answers where / when / how?)
the gate · the flag · a medalat the gate · after lunch · very fast · home

A fake object can’t hold up a verb that needs a real one. But a verb that takes no object is happy to carry one: Lena arrived at the gate.

Done looks like: you reach the 🚩 summit. The platforms start sliding, so steer early.

Climb 3 — Sneak Peek: Tricky Verbs

A sneak peek at next class PREVIEW

These verbs come in look-alike pairs: raised / rose, set / sat, laid / lay. In each pair, one needs an object and one doesn’t.

Nobody expects you to know which is which yet. Experiment! Watch what each one does, and see if you can work out the pattern before the summit.

Done looks like: you reach the 🚩 summit, and you can say which verb in each pair needed an object.
